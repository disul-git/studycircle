# StudyCircle
 
A student community web app for sharing study notes, asking academic questions, and organising study groups. Built with HTML, CSS, JavaScript, PHP and MySQL.
 
Final group project for **Web and Mobile Application Development** (Group 47).

## 1. About the project
 
StudyCircle lets students share notes and past papers, ask and answer questions, and form study groups. Admins approve uploads, manage subjects and categories, moderate content, and view reports.
 
### Student features
 
- Register and log in
- Browse resources and filter by subject
- View a resource, download it, rate it and comment on it
- Upload notes (they stay pending until an admin approves them) and view "My uploads"
- Ask questions and post answers in the forum
- Create and join study groups
- Schedule study sessions for a group
### Admin features
 
- Admin login and dashboard
- Manage users (including blocking)
- Approve or reject pending notes
- Manage subjects and categories
- Moderate forum questions, answers and comments
- View reports
